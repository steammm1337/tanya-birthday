BRICKVERSE — интерактивный LEGO-сайт
=====================================

КАК ОТКРЫТЬ
-----------
Просто открой файл index.html двойным кликом в браузере (Chrome/Edge/Firefox).
ИНТЕРНЕТ НЕ НУЖЕН — three.js, GSAP и 3D-модели вшиты прямо в папку (vendor/ + models.js).
Работает полностью оффлайн, без сервера. (Шрифты подгружаются с интернета,
если он есть; без него подставятся системные — сайт всё равно работает.)

ФАЙЛЫ
-----
index.html   — разметка
style.css    — стили (liquid glass, градиент, блочный LEGO-дизайн)
script.js    — вся логика (three.js + GSAP)
models.js    — 3D-модели в base64 (машинка + минифигурка)
models/      — исходные .glb (car.glb, minifig.glb) — для хостинга, если захочешь

ЧТО ВНУТРИ
----------
• Mr. Gold (минифигурка) вращается на пьедестале рядом с названием
• Машинка с камерой сверху едет за курсором по LEGO-плите со студами
• На телефоне машинка едет в ту сторону, куда скроллишь
• Клик/тап по площадке — машинка «бибикает» и роняет кирпичик
• Liquid glass + анимированный цветной градиент
• GSAP: появление секций + zoom-приближение при скролле
• Лёгкая пикселизация всего ОДИН раз при первом скролле (потом отключается)
• Падающие LEGO-кирпичики на фоне, кастомный курсор-кирпичик
• Блочные LEGO-шрифты (Luckiest Guy / Bungee / Fredoka)
• Полная адаптация под телефон

Фан-проект, не связан с LEGO Group.
